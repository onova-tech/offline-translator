# Data model: More languages in the Translator (spec 080)

Adds to spec 012's data model (`specs/012-offline-translator/data-model.md`); nothing there changes meaning.

## OfferedLanguage (generated catalog, `core/domain`)

| Field | Type | Notes |
|---|---|---|
| `code` | `LanguageCode` | Mozilla's code: `fr`, `ja`, `zh`, `zh_hant` |
| `pack` | `PackId` | `translate_<code>`; English has none |
| `quality` | `FULL` \| `BASIC` | `BASIC` when either direction is a `tiny` model (R1) |
| `tag` | `String` | the language tag for names and speech: `zh-Hans`, `zh-Hant`, `nb` |
| `speechRegion` | `String` | default speech tag: `fr-FR`, `zh-TW`; the phone's region wins (R5) |

`LanguageCatalog.all`: English and the 53 languages of R1, generated by `scripts/update-language-catalog.py` and
committed. `LanguageCatalog.of(code)` is null for a code it doesn't know.

## TranslatorSettings (spec 012) + checked languages

| Field | Type | Default | Rule |
|---|---|---|---|
| `languages` | `List<LanguageCode>?` | null → en, pt, es | the checked set; read through `CheckedLanguages.resolve`: unknown codes dropped, duplicates dropped, fewer than two → the default |

`schemaVersion` stays 1 (an optional field; R8). The `translator` data part exports it like the other settings.

## CheckedLanguages (domain rules, test-first)

- `resolve(stored)`: as above.
- `toggle(set, code)`: adds a language, or removes it unless only two are checked (then unchanged; the page shows why).
- `locked(set)`: the codes that can't be unchecked now (both, when two are checked).
- `replacementFor(removed, other, set)`: when a chosen language is unchecked, the first checked language by name that
  isn't `other` (FR-008); by name means as `LanguageNames` gives it in the app's language, so the order is passed in.

## LanguageNames (port, `core/domain`)

- `nameOf(tag, appLanguage): String` — "Japanese", "Japonês", "Japonés".
- `ownName(tag): String` — "日本語", capitalised where the language does ("Français").

## Language lists (presentation)

`languagesOf(statuses, checked)` (spec 012) now takes the checked set: installed checked languages first, then checked
ones to download with their size; English counts as installed. Settings' list: the checked languages, then installed
packs of unchecked ones.
